SADRA_SHOP — راهنمای اجرا

1) فایل ZIP را از حالت فشرده خارج کنید.
2) برای دیدن فروشگاه، فایل index.html را باز کنید.
3) برای پنل مدیریت، فایل admin.html را باز کنید.
4) محصولات، سبد خرید، سفارش‌های نمایشی و پیام‌های پشتیبانی در localStorage همان مرورگر ذخیره می‌شوند.

امکانات:
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- جست‌وجو و فیلتر محصولات
- سبد خرید و فرم ثبت سفارش نمایشی
- پنل افزودن/حذف محصول
- تغییر وضعیت سفارش‌های نمایشی
- دیدن/حذف پیام‌های پشتیبانی
- فهرست داخلی مدیران و نقش پیشنهادی پشتیبانی

مهم:
این نسخه فرانت‌اند و نمونه اولیه است، نه فروشگاه آماده فروش واقعی. ورود امن، دسترسی واقعی مدیران، دیتابیس مشترک، آپلود تصویر، API و پرداخت آنلاین ندارد. برای استفاده واقعی باید بک‌اند و دیتابیس راه‌اندازی شود.
